# Day 29 – Animated Skill/Progress Bars

## 📌 Project Overview
This project displays technical skills using animated progress bars. Each bar represents a skill level and smoothly fills according to its percentage when the webpage loads.

## ✨ Features
- Displays multiple technical skills.
- Animated progress bars using CSS transitions.
- JavaScript dynamically sets the width of each bar.
- Uses `data-width` to define skill percentages.
- Responsive design for mobile devices.
- Simple and clean user interface.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
```text
Animated-Skill-Progress-Bars/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ⚙️ How It Works
1. HTML creates the skill section and progress bars.
2. CSS styles the bars and adds smooth width transitions.
3. JavaScript selects the progress bars and reads their target widths from the `data-width` attribute.
4. When the webpage loads, JavaScript sets each bar to its target width.

## 💻 Example
```html
<div class="progress-container">
    <div class="progress" data-width="90%"></div>
</div>
```

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. View the animated skill progress bars.
